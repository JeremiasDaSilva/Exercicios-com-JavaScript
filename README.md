# 💻 Exercícios Práticos com JavaScript

Projeto desenvolvido para a disciplina de programação na **ETEC**, contendo exercícios introdutórios de lógica e manipulação do DOM com **HTML5**, **CSS3** e **JavaScript**.

---

## 📋 Sobre o Projeto

A aplicação apresenta uma interface web interativa dividida em cartões, onde o usuário pode inserir dados diretamente na tela e visualizar os resultados tanto na página quanto no console do navegador.

### Funcionalidades Implementadas
1. **Exercício 1 – Apresentação:** Captura o nome digitado pelo usuário e exibe uma mensagem de apresentação personalizada.
2. **Exercício 2 – Soma de Números:** Recebe dois valores numéricos, realiza a soma e exibe o resultado na tela e no console.
3. **Exercício 3 – Subtração:** Recebe dois valores numéricos, calcula a diferença entre eles e apresenta o resultado.

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página e formulários de entrada.
* **CSS3:** Estilização moderna com Flexbox, cartões responsivos e faixas decorativas laterais.
* **JavaScript (ES6+):** Lógica de programação, funções, manipulação do DOM e saída de dados via `console.log()`.

## 🔧 Como Executar o Projeto

1. Clone este repositório ou baixe os arquivos:
   ```bash
   git clone https://github.com
   ```
2. Acesse a pasta **`Exercícios com Javascript`**.
3. Dê um clique duplo no arquivo **`index.html`** para abri-lo em qualquer navegador (ou utilize a extensão *Live Server* no VS Code).
4. *(Opcional)* Pressione **`F12`** no navegador e abra a aba **Console** para acompanhar os registros de saída em tempo real.
